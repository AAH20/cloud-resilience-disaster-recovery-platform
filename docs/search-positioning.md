# Search and hiring evidence

Exact search volume varies by region, platform and date. This project maps high-demand terms to implementation and explicit boundaries rather than inventing counts.

| Term | Evidence | Boundary |
|---|---|---|
| Cloud Computing / Cloud Architecture | Multi-service recovery model | Synthetic environment |
| Disaster Recovery / Business Continuity | Recovery compiler, RTO/RPO and transaction gates | Implemented evidence engine |
| Microsoft Azure / Multi-Region | Azure regional-loss case study and IaC | No live failover claimed |
| Kubernetes / AKS Disaster Recovery | Cluster and transaction recovery architecture | Integration path |
| High Availability / Database Failover | PostgreSQL zone-failover scenario | Modeled timing |
| Ransomware Recovery / Azure Backup | Immutable clean-room design | No restore executed |
| Chaos Engineering / Azure Chaos Studio | Controlled scenario contract | No experiment executed |
| SRE / Operational Resilience | RTO, RPO, integrity and rollback scorecard | Implemented |
| DevOps / Infrastructure as Code / Terraform | CI and Bicep evidence plane | Terraform roadmap |
| OpenTelemetry / Incident Response | Timestamp and transaction evidence contract | Telemetry adapter roadmap |
